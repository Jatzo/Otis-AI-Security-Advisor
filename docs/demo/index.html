Otis, replayed

Otis answers questions about vulnerabilities in 18 open-source packages from public advisories. Pick a question to see what the model said, what the checker did with it, the records it was shown, and the gold answer the question is scored against.

    These are dev questions, the set the system was tuned on, so the figures are not a test result. The test results are in the write-up. Otis cannot tell whether a list is complete, and an answer that passes the checker can still be wrong. If Otis finds nothing, that is not a promise something is safe.

    Advisory text is from the GitHub Advisory Database, licensed CC BY 4.0, with changes: records are cut to a short excerpt. This product uses data from the NVD API but is not endorsed or certified by the NVD. Known-exploited data is from CISA.

    The project is on GitHub. The red team report says what was attacked and what held.
